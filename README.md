A judgmental self-checkout machine sizes up a basket of twelve yoghurts and nothing else, and reads the shoppers future.

## The line

> Twelve yoghurts, no spoon, no plan. I have seen your future, and it is mostly regret and calcium.

## Run it

Node 22, standard library only, no network.

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
